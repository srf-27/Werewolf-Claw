使用帮助

聊天页面的常见操作说明。接口细节见 /api-docs，仓库里还有 docs/api.md。

基本对话

  • 在底部输入框输入内容，回车发送，Shift+回车换行。
  • 发送后你的消息会立刻出现，助手一侧先显示「正在思考…」，拿到回复后自动替换。
  • 把鼠标放到某条消息上，可以在消息上方看到发送时间，下方出现操作图标。

消息操作

  • 复制：把这条消息的正文复制到剪贴板。
  • 引用：把这条消息作为引用附在输入框上方，再写你要问的内容；引用只在当前会话内有效，切换会话会自动清掉。
  • 编辑（只在最近一条用户消息上）：撤回这一轮问答，用修改后的内容重新提问，助手上一轮的回复会从上下文和记忆里删掉。
  • 重新生成（助手消息）：重新生成这条回复，一条回复最多 5 次；每次都先总结之前回答的不足再给出新的回答，旧回答不再显示，只显示「重新生成 n/5」。

会话

  • 左侧按时间分组：置顶、今天、昨天、7 天内、30 天内、年份-月份。
  • 右键会话可以重命名、置顶、取消置顶、删除。
  • 点「多选」进入多选模式，勾选多个会话后可以批量置顶、取消置顶、删除。
  • 进入会话默认显示最近一屏消息，想看更早的点顶部的「更多历史」。
  • 左上「＋ 新建会话」开一个新会话；标题在第一轮对话后自动总结，你手动重命名后不再自动改动。

导入导出

  • 「导出」把当前会话（消息、摘要、长期记忆、标题）下载成 JSON。
  • 「导入」选择导出的 JSON 还原会话；原会话 id 已存在时会自动换一个新 id，不会覆盖已有会话。

模型配置

  • 左下角齿轮按钮打开设置菜单，里面可以进入「模型配置」。
  • 可以保存多套配置（最多 8 套），填写名称、API Key、Base URL、模型名，点「使用」切换当前生效的那套；卡片支持拖动排序、复制、删除。
  • 配置写进项目根目录的 .env，保存后立即生效，不用重启服务。密钥在页面上只显示打码结果。
  • 同一个菜单里可以切换夜间模式，设置存在浏览器本地。

数据存在哪里

  • 会话数据存在项目根目录的 memory/chat.db（SQLite），按会话 id 隔离。
  • 模型配置存在项目根目录的 .env，这两个文件都不该提交到仓库。
  • 长期记忆只在你明确说「记住…」时才写入；上下文用到 90% 时会自动压缩成摘要。

常见问题

  • 报 401 / Incorrect API key：API Key 和 Base URL 不匹配。用 OpenAI 官方密钥就把 Base URL 留空，用第三方服务（例如 https://api.deepseek.com/）要填对应的地址。
  • 报模型不存在：模型名要和服务商的文档一致，例如 DeepSeek 用 deepseek-chat。
  • 刷新后会话还在吗：在，记录在 memory/chat.db；换电脑用「导出 / 导入」搬。
