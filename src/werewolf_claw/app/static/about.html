它能做什么

  • 多轮对话，历史消息落库，重启后继续聊。
  • 会话按时间分组管理，支持置顶、重命名、多选批量删除、导入导出。
  • 用户说「记住…」时写入长期记忆；上下文到 90% 自动压缩成摘要，保留最近几轮。
  • 消息支持复制、引用、编辑重发；助手回复可以重新生成，最多 5 次，每次先总结不足再重写。
  • 多套模型配置，随时切换，支持夜间模式。

技术栈

  • 后端：FastAPI + uvicorn，接口见 /api-docs
  • 模型调用：openai SDK（兼容 OpenAI 协议的服务都能接）
  • 存储：SQLite（标准库 sqlite3）
  • 前端：原生 HTML / CSS / JavaScript，无构建步骤
  • 包管理：uv
